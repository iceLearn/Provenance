# Beyond the Provenance Pin — CHI 2027 Workshop website

Single-page static site (no build step). Deploys as GitHub Pages at
`https://<github-username>.github.io/Provenance/`.

## Files
- `index.html` — the whole site (CSS + JS inline). Organizer list is the `PEOPLE` array near the bottom.
- `assets/fig1-pipeline.png`, `assets/fig2-activities.png` — figures from the proposal (fig 1 is the social-preview image).

## Deploy
1. Create a public GitHub repo named **Provenance**.
2. Push the contents of this folder to `main`.
3. Repo → Settings → Pages → Source: *Deploy from a branch*, Branch: `main` / `(root)`.
